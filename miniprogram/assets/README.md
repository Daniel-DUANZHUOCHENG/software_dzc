# 资源文件目录说明

```
assets/
├── banners/         # 轮播图资源
│   ├── banner1.jpg  # 会议通知banner
│   └── ...
├── icons/           # 图标资源
│   ├── home.png     # 首页图标
│   ├── home-active.png
│   ├── dynamic.png  # 动态图标
│   ├── dynamic-active.png
│   ├── tech.png     # 技术图标
│   ├── tech-active.png
│   ├── cooperation.png  # 合作图标
│   ├── cooperation-active.png
│   └── arrow-right.png  # 箭头图标
├── partners/        # 合作伙伴logo
│   ├── daop.png    # 道普信息logo
│   └── ...
└── meetings/       # 会议相关图片
    ├── meeting1.jpg # 会议封面图
    └── ...
```

## 图片规范

1. 轮播图（banners）
   - 尺寸：750x400px
   - 格式：JPG
   - 文件大小：建议小于200KB

2. 图标（icons）
   - 尺寸：48x48px
   - 格式：PNG（支持透明背景）
   - 文件大小：建议小于20KB
   - 命名规则：
     - 普通状态：icon-name.png
     - 选中状态：icon-name-active.png

3. 合作伙伴logo（partners）
   - 尺寸：120x120px
   - 格式：PNG（支持透明背景）
   - 文件大小：建议小于50KB

4. 会议图片（meetings）
   - 尺寸：400x300px
   - 格式：JPG
   - 文件大小：建议小于150KB

## 注意事项

1. 所有图片必须经过压缩优化，可使用 [tinypng](https://tinypng.com/) 等工具
2. 图片命名使用小写字母，单词间用连字符（-）分隔
3. 保持资源文件结构整洁，不使用的资源及时清理
4. 图片尺寸保持统一，便于界面布局
