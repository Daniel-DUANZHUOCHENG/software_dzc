# 软件系统开发实训（2023 级） - P1-测盟汇 项目

本项目是"软件系统开发实训"课程的实践项目，旨在为"电子质量管理协会计算机软硬件和信息系统质量测评分会"开发一套完整的解决方案，以解决其在会议组织、信息发布和知识共享等方面遇到的痛点。

项目基于 B/S 架构，包含一个功能强大的 **Web 管理端** 和一个便捷的 **移动端**。

## 🎯 核心功能需求

### Web 管理端

- [ ] **用户管理子系统**:
  - [ ] 企业注册与登录
  - [ ] 多角色支持（企业用户、超级管理员）
  - [ ] 个人资料与密码修改
  - [ ] 管理员对用户的管理与权限控制
- [ ] **行业动态管理子系统**:
  - [ ] 动态的发布（富文本编辑器）、编辑、删除
  - [ ] 管理员审核流程
  - [ ] 用户按条件浏览和搜索
- [ ] **课程管理子系统**:
  - [ ] 课程的增、删、改、查与搜索
  - [ ] 管理员对企业用户提交课程的审核
- [ ] **会议管理子系统**:
  - [ ] 会议的创建、编辑、删除
  - [ ] 管理员审核流程
  - [ ] 会议详情浏览

### 移动端

- [ ] **会议注册子系统**:
  - [ ] 按类别展示会议列表
  - [ ] 查看会议详情
  - [ ] 在线填写和提交参会回执
- [ ] **行业动态子系统**:
  - [ ] 列表展示（支持下拉刷新/上拉加载）
  - [ ] 模糊搜索
  - [ ] 图文详情展示

### 可选功能 (挑战)

- [ ] 微信快速登录
- [ ] 用户行为数据分析并在管理端以图表展示

## 🚀 快速开始

### 环境准备

- [Git](https://git-scm.com/)
- [JDK](https://www.oracle.com/java/technologies/downloads/) (1.8 或更高版本)
- [Maven](https://maven.apache.org/download.cgi)
- [Node.js](https://nodejs.org/) (14.x 或更高版本)
- [MySQL](https://www.mysql.com/downloads/) (5.7 或更高版本)

### 后端启动

1.  **克隆项目**
2.  **数据库设置**:
    - 创建一个名为 `cmh` 的 MySQL 数据库。
    - 导入项目所需的 SQL 文件以初始化表结构和数据。
    - 修改 `总体项目/后端/OAASystem/OAASystem/src/main/resources/application.properties` 中的数据库连接信息。
3.  **启动应用**:
    - 在 IDE (如 IntelliJ IDEA) 中打开 `总体项目/后端/OAASystem` 目录。
    - 运行 `OaaSystemApplication.java`。服务将启动在 `http://localhost:9049`。

### 前端启动

1.  **进入前端目录**: `cd 总体项目/web前端`
2.  **安装依赖**: `npm install`
3.  **运行开发服务器**: `npm run dev`
4.  **访问应用**: 在浏览器中打开 Vite 提供的本地访问地址。
